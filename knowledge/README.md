# Knowledge

Durable marketing theory. Vendor-agnostic, store-agnostic, and stable — these documents change when
marketing understanding changes, not when a skill or a platform changes.

## Knowledge vs rules vs skills

| | Answers | Changes when |
|---|---|---|
| **Knowledge** | *Why does this work?* | Marketing understanding changes |
| **Rules** | *What is never acceptable?* | Policy or risk posture changes |
| **Skills** | *What do I do for this objective?* | The workflow changes |

A skill links to knowledge for reasoning it should not restate, and to rules for constraints it must
obey. If the same explanation appears in three skills, it belongs here.
