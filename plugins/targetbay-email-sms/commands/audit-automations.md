---
description: Audit the automation portfolio and sequence the work by expected value
---

Use the `automation-strategy` skill.

Ask which automations this store should have at all: find lifecycle stages with no coverage, and
decide which existing journeys should be split, consolidated, extended or retired. Do not assume one
objective means one automation.

Rank the work by expected value with the evidence for each, and hand individual builds to
`automation-architect`.

Plan only. Creating or activating an automation needs explicit human approval
(`rules/safety-rules.md`).
