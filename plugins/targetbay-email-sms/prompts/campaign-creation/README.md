# Campaign Creation prompts

Shaping new campaigns: structure, subject lines, personalisation, launches and cross-sell. Each prompt routes to one skill in this plugin.

| Prompt | What you get | Skill |
|---|---|---|
| [Blueprint a Reusable Email Structure](build-email-template.md) | A block-by-block email layout for one campaign type, from lead and proof to products and a single CTA. | [`content-optimization`](../../skills/content-optimization/SKILL.md) |
| [Personalise Beyond First Name](find-personalization-opportunities.md) | Which parts of my messages should vary per recipient, driven only by data I actually have. | [`dynamic-content-personalizer`](../../skills/dynamic-content-personalizer/SKILL.md) |
| [Subject Line Variants Worth Testing](generate-subject-line-variants.md) | Subject line directions across distinct angles for one send, with the pair to test first. | [`content-optimization`](../../skills/content-optimization/SKILL.md) |
| [Plan a Product Launch Sequence](plan-product-launch.md) | A wave-by-wave launch plan showing who hears first, on which channel, with content direction and follow-through. | [`product-launch`](../../skills/product-launch/SKILL.md) |
| [Cross-Sell After the First Purchase](post-purchase-cross-sell.md) | Evidence-based next-category recommendations for recent buyers, with audience, moment and channel. | [`cross-sell`](../../skills/cross-sell/SKILL.md) |
