# Knowledge

Durable reasoning about loyalty programmes and member behaviour. Skills link here for *why* something is
true, so the explanation lives in one place and the skills stay about decisions.

| File | Covers |
|---|---|
| [loyalty-principles.md](loyalty-principles.md) | Why programmes work, where their value actually is |
| [member-lifecycle.md](member-lifecycle.md) | How membership behaves over time |

## What belongs here

Reasoning that stays true across stores and does not depend on this month's data. If a paragraph explains
*why*, it belongs here. If it decides *what to do*, it belongs in a skill. If it forbids something, it
belongs in [../rules/](../rules/README.md).

## What does not belong here

- Numbers presented as universal. Earn rates, thresholds and point values are derived per store
  ([../rules/global-rules.md#G3](../rules/global-rules.md))
- External benchmarks stated as this store's data
- Anything that restates a rule; cite the rule instead
