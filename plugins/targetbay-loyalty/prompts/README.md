# TargetBay Rewards prompt library

Copy-paste prompts for an AI assistant connected to the TargetBay Loyalty MCP (Rewards is the
merchant-facing name for this plugin). Each one routes to a
single skill in this plugin, derives every threshold from your store data, and stops for your approval
before anything changes or sends. Replace any `[BRACKETED]` placeholder before pasting.

| Category | Covers | Prompts |
|---|---|---|
| [Diagnosis](diagnosis/README.md) | Finding out what my rewards program is actually doing before changing it | 4 |
| [Member Engagement](member-engagement/README.md) | Winning back quiet members and running referrals that bring customers who stay | 5 |
| [Program Design](program-design/README.md) | Deciding whether to run a rewards program and setting its shape and economics | 6 |
