# Diagnosis prompts

Finding out what my rewards program is actually doing before changing it. Each prompt routes to one skill in this plugin.

| Prompt | What you get | Skill |
|---|---|---|
| [Check Rewards Messages Reach Members](audit-rewards-messages-reach.md) | Whether balance, tier and expiry messages reach members and lead to redemptions and repeat orders. | [`program-diagnosis`](../../skills/program-diagnosis/SKILL.md) |
| [Map My Enrolment to Redemption Funnel](map-enrolment-to-redemption-funnel.md) | Where members drop between enrolling, earning and redeeming, and the constraint that matters most. | [`program-diagnosis`](../../skills/program-diagnosis/SKILL.md) |
| [Check Whether Tiers Change Behaviour](check-whether-tiers-change-behaviour.md) | Whether each tier actually changes what members buy, or just labels them. | [`program-diagnosis`](../../skills/program-diagnosis/SKILL.md) |
| [Test Whether Rewards Drives Extra Orders](test-whether-rewards-drives-extra-orders.md) | An honest read on whether my rewards program adds orders or just rewards customers who'd buy anyway. | [`program-diagnosis`](../../skills/program-diagnosis/SKILL.md) |
