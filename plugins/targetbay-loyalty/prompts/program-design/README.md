# Program Design prompts

Deciding whether to run a rewards program and setting its shape and economics. Each prompt routes to one skill in this plugin.

| Prompt | What you get | Skill |
|---|---|---|
| [Decide Whether to Launch Rewards](should-i-launch-a-rewards-program.md) | An evidence-based yes or no on running a rewards program for my store. | [`program-design`](../../skills/program-design/SKILL.md) |
| [Design My First Rewards Program](design-my-first-rewards-program.md) | A lean first-version program covering rewards, enrolment, entry reward and measurement. | [`program-design`](../../skills/program-design/SKILL.md) |
| [Set My Earn Rate and Point Value](set-earn-rate-and-point-value.md) | What a point is worth, what it costs per order, and an earn rate my margin can carry. | [`points-economics`](../../skills/points-economics/SKILL.md) |
| [Price Rewards Against My Margin](price-rewards-against-margin.md) | Reward prices set against real margin and redemption capacity, not round point numbers. | [`points-economics`](../../skills/points-economics/SKILL.md) |
| [Check My Points Liability](check-my-points-liability.md) | The size and age of my outstanding points, and what to do about it. | [`points-economics`](../../skills/points-economics/SKILL.md) |
| [Decide Whether Tiers Pay Off](decide-whether-tiers-pay.md) | Whether tiers fit my customer value spread and, if so, thresholds and benefits costed per tier. | [`tier-structure`](../../skills/tier-structure/SKILL.md) |
