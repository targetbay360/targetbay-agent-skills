description: Map what is currently running on every onsite surface and what each element is worth
---

Use the `surface-inventory` skill.

Read consent state first, and report what is currently permissible as well as what is currently
configured — where those differ, that is the most important finding.

Name the decision each surface hosts. A placement sitting in front of no decision is decoration regardless
of its engagement numbers, and elements are judged on outcome rather than impressions.

Report surfaces that host a real decision and carry nothing, alongside the crowded ones. State the
anonymous share of traffic explicitly.

Analysis only — no changes (`rules/safety-rules.md`).
