# Knowledge

Durable reasoning about onsite personalization and visitor behaviour. Skills link here for *why* something
is true, so the explanation lives in one place and the skills stay about decisions.

| File | Covers |
|---|---|
| [personalization-principles.md](personalization-principles.md) | Why personalization works, and where its value actually is |
| [visitor-behaviour.md](visitor-behaviour.md) | How visitors move, and what signals are available when |

## What belongs here

Reasoning that stays true across stores and does not depend on this month's data. If a paragraph explains
*why*, it belongs here. If it decides *what to do*, it belongs in a skill. If it forbids something, it
belongs in [../rules/](../rules/README.md).

## What does not belong here

- Numbers presented as universal. Uplift, thresholds and traffic shares are derived per store
  ([../rules/global-rules.md#G3](../rules/global-rules.md))
- External benchmarks stated as this store's data
- Anything that restates a rule; cite the rule instead
