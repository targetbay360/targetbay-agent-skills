# TargetBay Reviews prompt library

Copy-paste prompts for an AI assistant connected to the TargetBay Reviews MCP. Each one routes to a
single skill in this plugin, derives every threshold from your store data, and stops for your approval
before anything changes or sends. Replace any `[BRACKETED]` placeholder before pasting.

| Category | Covers | Prompts |
|---|---|---|
| [Program Audit](program-audit/README.md) | Open-ended health checks of the whole review and UGC program | 3 |
| [Rating Health](rating-health/README.md) | Understanding why ratings move and responding to the cause | 3 |
| [Review Requests](review-requests/README.md) | Collecting more and better reviews: when, how and whom to ask | 4 |
| [Social Proof](social-proof/README.md) | Finding where proof is missing and putting existing proof where shoppers decide | 5 |
