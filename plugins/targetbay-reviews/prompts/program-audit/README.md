# Program Audit prompts

Open-ended health checks of the whole review and UGC program. Each prompt routes to one skill in this plugin.

| Prompt | What you get | Skill |
|---|---|---|
| [Find What to Fix First in Reviews](find-what-to-fix-first-in-reviews.md) | A ranked list of review program fixes, with the one constraint capping everything else. | [`review-program-audit`](../../skills/review-program-audit/SKILL.md) |
| [Check Review Moderation and Replies](check-review-moderation-and-replies.md) | How my moderation queue and reply habits are shaping trust, and what to change first. | [`review-program-audit`](../../skills/review-program-audit/SKILL.md) |
| [Map Review Coverage Across My Catalogue](map-review-coverage-across-catalogue.md) | Review coverage by category, price band and product age, showing where the program falls short. | [`review-coverage`](../../skills/review-coverage/SKILL.md) |
