# Review Requests prompts

Collecting more and better reviews: when, how and whom to ask. Each prompt routes to one skill in this plugin.

| Prompt | What you get | Skill |
|---|---|---|
| [Time Review Requests to Delivery](time-review-requests-to-delivery.md) | Request triggers and delays derived per product from when customers actually receive and use it. | [`review-request-program`](../../skills/review-request-program/SKILL.md) |
| [Find Why Review Submissions Are Low](find-why-review-submissions-are-low.md) | The exact stage where my review request funnel leaks, and the fix for that stage. | [`review-request-program`](../../skills/review-request-program/SKILL.md) |
| [Get More Photo and Video Reviews](get-more-photo-and-video-reviews.md) | A separate media ask aimed at the products where photos and video would help shoppers most. | [`review-request-program`](../../skills/review-request-program/SKILL.md) |
| [Point Review Requests at Proof Gaps](point-review-requests-at-proof-gaps.md) | Review requests prioritised by the products that most need proof, not by order volume. | [`review-request-program`](../../skills/review-request-program/SKILL.md) |
